##  Header
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Magic Number | Must always be 0x55504D4B |
| 4 - 7 | 4 Bytes | Body Offset | The distance between the start of the file and the start of the Body |
| 8 - 11 | 4 Bytes | Extra Files Offset | The distance between the start of the file and the start of the Extra Files list |
| 12 - 15 | 4 Bytes | Style Offset | The distance between the start of the files and the start of the Style list |
| 16 - 19 | 4 Bytes | Content Offset | The distance between the start of the file and the start of the Content list |
| 20 - 23 | 4 Bytes | Free data Offset | The distance between the start of the file and the start of the Free data list |
| 24 | 1 Byte | Title string Length | The distance between the next byte and the end of the title string |
| ? | N Bytes | Title String | A String used for the title of the page |

## Extra Files
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Count | How much extra files there are to include |
| ? | ? Bytes | Data | Seperated into [Blocks](#extra-files-blocks), put after eachother |

### Extra Files Blocks
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 1 | 2 Bytes | Size | Determines the size of the string |
| 2 - N | \[Size\] Bytes | String | A large string of ASCII characters with the size of the item above here \(Size\) |

## Body
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Count | How much elements there are in the tree |
| ? | ? Bytes | Elements | Seperated into [Elements](#body-elements), put after eachother |

### Body Elements
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 4 | 4 Bytes | First Child | Pointer to the First child, interpreted as index in the Body list, if 0: no child |
| 5 - 7 | 4 Bytes | Next Sibling | Pointer to the next element on the same level, interpreted as index in the Body list, if 0: no sibling |
| 8 - 11 | 4 Bytes | Parent | Pointer to the parent element, interpreted as index in the Body list, if 0: at Root level |
| 12 - 15 | 4 Bytes | Style | Pointer to the [style element](#style), interpreted as index in the Style list, if 0: [default style](#default-style) |
| 16 - 19 | 4 Bytes | Content | Pointer to the [content element](#content), interpreted as index in the Content list, if 0: [Canvas Template](#content-templates) |
| 20 - 23 | 4 Bytes | Data | Pointer to the [free data element](#free-data), interpreted as index in the Free data list, if 0: No data |

## Style
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Count | How much elements there are in the list |
| ? | ? Bytes | Elements | Seperated into [Elements](#style-elements), put after eachother |

### Style Elements
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 4 | 4 Bytes | Bitmask | Tells exactly which [Style blocks](#style-blocks) are used in this element, every bit stands for a number ID in ascending order from 0 for the first bit to 31 for the last bit |
| ? | ? Bytes | Data | Seperated into [blocks](#style-blocks), put after eachother in order of number ID |

### Style Blocks
Style blocks are split into fields that follow eachother, the value in these fields is built up like this:
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 1 | 2 Bytes | Length | Determines the length of the formula |
| 2 - N | N Bytes | Fomrula | Contains the [formula](/docs/formula.md) |

There are 32 style blocks, each one has specific fields and influences, they are listed in this table down here:

## Content
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 | 1 Byte | Template | Determines the [template](#content-templates) used for the content |
| ? | ? Bytes | Data | Data, method of interpretation determined by templates |

### Content templates
The index in the following list tells which value of the template byte in the content element belongs to which template.

0. [Text](#content-template-text)
1. [Canvas](#content-template-canvas)

### Content template Text
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Length | Determines the length of the string |
| 4 - N | N Bytes | String | UTF-8 Text, length in bytes determined by Length value ^^^ |

### Content template Canvas
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Buffer ID | Tells which runtime canvas buffer to pull the image to show from, if 0: solid transparent color |

## Free Data
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 1 | 2 Bytes | Size | Determines the size of the data in bytes |
| 2 - N | N Bytes | Data | Any data can be written into here, size in bytes determined by size value ^^^ |
