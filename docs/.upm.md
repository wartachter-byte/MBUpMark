##  Header
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Magic Number | Must always be 0x55504D4B |
| 4 - 7 | 4 Bytes | Body Offset | The distance between the start of the file and the start of the Body |
| 8 - 11 | 4 Bytes | Extra Files Offset | The distance between the start of the file and the start of the Extra Files list |
| 12 | 1 Byte | Title string Length | The distance between the next byte and the end of the title string |
| ? | N Bytes | Title String | A String used for the title of the page |

## Extra Files
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Count | How much extra files there are to include |
| ? | ? Bytes | Data | Seperated into [Blocks](#extra-files-blocks), put after eachother |

### Extra Files Blocks
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 1 | 2 Bytes | Size | Determines the size of the string |
| 2 - N | \[Size\] Bytes | String | A large string of ASCII characters with the size of the item above here \(Size\) |

## Body
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 3 | 4 Bytes | Count | How much elements there are in the tree |
| ? | ? Bytes | Elements | Seperated into [Elements](#body-elements), put after eachother |

### Body Elements
| Byte(s) | Size | Name | Description |
| :---: | :---: | :---: | :---: |
| 0 - 4 | 4 Bytes | First Child | Pointer to the First child, interpreted as index in the Body list, 0 if no child |
| 5 - 7 | 4 Bytes | Next Sibling | Pointer to the next element on the same level, interpreted as index in the Body list, 0 if no sibling |
| 8 - 11 | 4 Bytes | Parent | Pointer to the parent element, interpreted as index in the Body list, if 0: at Root level |
